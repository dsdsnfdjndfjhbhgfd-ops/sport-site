# Структура каталога s-ekip.ru («Торговый каталог»)

Источник: https://s-ekip.ru/ords/r/akiaer/js/cat (ООО «СпортЭкипЦентр»). Собрано 25.10.2026
скриптом `scripts/ekip/scrape.mjs`, гостевой доступ без входа. Во время сбора сайт показывал
плашку «сайт доступен в режиме только для чтения — проводятся технические работы».

Платформа — Oracle APEX (приложение 110, страница 307). Весь каталог — **одна страница**.
Карточки товаров выводит регион Cards, фильтры — регион Faceted Search. Окно товара — модальный
диалог на той же странице. Отдельных HTML-страниц для категорий и товаров нет.

На странице «Каталоги» (`/ords/r/akiaer/js/catalogs`) три раздела:
- **Торговый каталог** — товары в наличии, с корзиной. Собран именно он.
- **Номенклатор (полный)** — `/ords/r/akiaer/js/nom`, все позиции, «только посмотреть». Не собирался.
- **Сезонные коллекции** — PDF, `/ords/r/akiaer/js/catalogpdf`. Не собирался.

## 3. Сортировка

Переключателя сортировки в каталоге **нет** (на странице не найдено ни контрола, ни
слова «сортировка»). Порядок карточек задаёт сервер.

## 4. Карточка товара в списке

Сетка карточек примерно по 17rem, на ширине 1400px — 3 в ряд. Поля карточки:

- **Название** — одной строкой: бренд, тип, модель, артикул, иногда пометки
  («KELME Кроссовки K-ROOKIE TEAM 46971-26», «CENTURION Гетры спортивные OPTIMAL 40001.06(013) СвСк»).
- **Иконки пола** (fa-user-man / fa-user-woman) и **цвет** текстом под названием.
- **Фото** (одно). При наведении фото переворачивается и показывает таблицу остатков
  «Размер | склад (ОСН/РАС)» (AJAX-процесс `LOADRESTMV`). Количество показывается числом,
  большое — как «>500».
- **Иконка в правом верхнем углу** — есть только у части карточек (на скриншоте — силуэт футболки
  с цифрой). Подписи на сайте нет. Судя по доле таких карточек, это может быть отметка об услуге
  «Нанесение», но это не проверено.
- Кнопки **«В корзину»** и **«Наличие»** (иконка-гистограмма, открывает окно с остатками).
- **Цена** — одна, например «6 599 ₽». **Старой цены и значков скидок/новинок не встретилось
  ни у одного из 727 товаров** (`old_price_rub` везде null).
- Артикул и бренд отдельными полями в карточке не выводятся: они только внутри названия.

## 5. Пагинация

Бесконечная прокрутка (APEX Cards, `pagination.scroll = true`). Номеров страниц и кнопки
«Показать ещё» нет. Порция — **21 карточка** (подгрузки 21 → 42 → 63…). Общее число товаров видно
только по счётчикам фасетов («В корзине: Нет 727»).

## 6. Окно товара («Описание товара»)

Модальный диалог поверх каталога. Открывается кликом по фото. Разделы сверху вниз:

1. **Шапка**: миниатюра, название, «Артикул: …», цена, текст описания, кнопки
   «Получить ссылку» (копирует прямую ссылку на товар) и «В корзину».
2. **Фото | Видео** — галерея; на изображениях бывает таблица размеров (размерная сетка картинкой).
3. **Варианты модели** — другие цвета той же модели (артикул, цвет, «В корзину»).
4. **Характеристики** — таблица: Назначение (вид спорта), Цвет, Пол, Единица измерения,
   Код ТН ВЭД, Страна производства, Вес (гр), Ширина/Высота/Длина упаковки (мм).
5. **Остатки модели** — таблица «Размер | Артикул | Цвет | Склад | Кол-во» по всем цветам
   модели. Размер обуви указан как «35 EUR/ 04 USA», склад — ОСН/РАС. Здесь количество
   показывается числом (до 500).
6. **Технологии** — блоки с названием и пояснением (например THERMOTECH, K-FLEX). Есть не у всех.

Отдельное окно **«Наличие»** (кнопка в карточке): название, цена, описание, «В корзину»,
таблица остатков по размерам.

## 7. Шаблоны URL

| Что | URL |
|---|---|
| Каталог | `https://s-ekip.ru/ords/r/akiaer/js/cat` (параметр `session=…` не обязателен) |
| Категория («Вид») | `https://s-ekip.ru/ords/r/akiaer/js/cat?p307_name_product_kind=ОБУВЬ` — проверено, фильтр применяется |
| Подкатегория («Тип») | своего URL нет. Параметр `p307_name_product_type` записывается в элемент страницы, но фасет не отмечается, поэтому в `categories.json` у подкатегорий стоит URL родительской категории |
| Товар | `https://s-ekip.ru/ords/r/akiaer/js/cat?request=show&P307_ID_PRODUCT_VIEW=<ID>` — этот формат даёт кнопка «Получить ссылку». ID — 32-символьный hex (`data-id` карточки) |
| Внутренние действия | `#action$v?id=<ID>` (окно товара), `#action$cart?id=<ID>`, `#action$rst?id=<ID>` (наличие) |

## 9. Поля в products.json

`category` / `subcategory` — значения фасетов «Вид» / «Тип». `name`, `price_rub`, `colors` —
из карточки. `brand` — значение фасета «Бренд», с которого начинается название (совпало у
всех 727). `sku` — «Артикул:» из окна товара. `sizes` — таблица остатков при наведении:
`stock` — число, если сайт показал точное количество, и `null`, если показал «>500» (43 размера).
Исходный текст лежит в `stock_raw`. Для товаров с остатками на двух складах есть `by_warehouse`
(встретился один такой товар). Дополнительные поля: `site_id` (ID товара на сайте) и `warehouses`
(склады в таблице остатков: ОСН — основной, РАС — распродажа). `summary` собрана из этих же
полей; тексты описаний с сайта не копировались. Фото не сохранялись.

Цены: от 299 до 49 849 ₽.
