# SPORTLINE — интернет-магазин спортивной одежды

Next.js 16 (App Router) + Prisma + SQLite. Внутри: каталог с категориями, поиском, сортировкой и скидками; регистрация и вход; корзина; оформление заказа с онлайн-оплатой; личный кабинет с историей заказов; админ-панель.

## Быстрый старт

```bash
npm install
cp .env.example .env      # затем поменяйте AUTH_SECRET и пароль админа
npm run setup             # создаёт базу и наполняет демо-товарами + админом
npm run dev               # http://localhost:3000
```

Админ по умолчанию: `admin@example.com` / `admin12345` (задаются в `.env` через `ADMIN_EMAIL` / `ADMIN_PASSWORD` до запуска `npm run setup`). Админ-панель: `/admin`.

## Админ-панель

- **Товары и цены** — список всех товаров, цену можно поменять прямо в таблице; скрыть/показать товар.
- **Добавить товар** — название, категория, цена, старая цена (для скидки), размеры, остаток, описание, фото (загрузка файла или ссылка).
- **Категории**, **Заказы** (смена статуса), **Пользователи** (выдать/снять права администратора).

## Оплата

Провайдер выбирается переменной `PAYMENT_PROVIDER`:

| Значение | Что происходит |
|---|---|
| `mock` (по умолчанию) | Тестовая страница оплаты внутри сайта, без внешних сервисов |
| `yookassa` | ЮKassa. Нужны `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` (тестовый магазин в личном кабинете ЮKassa). URL уведомлений: `https://ваш-домен/api/webhooks/yookassa` |
| `stripe` | Stripe Checkout. Нужен `STRIPE_SECRET_KEY` (`sk_test_…`), для вебхуков — `STRIPE_WEBHOOK_SECRET`, endpoint `https://ваш-домен/api/webhooks/stripe` |

Статус платежа проверяется и при возврате покупателя на сайт, и по вебхуку. Цены при оформлении всегда пересчитываются на сервере из базы. Чтобы добавить другого провайдера (CloudPayments, Т-Банк и т.п.), реализуйте интерфейс `PaymentProvider` из `src/lib/payments/types.ts` и зарегистрируйте его в `src/lib/payments/index.ts`.

## Структура

```
prisma/schema.prisma        модели: User, Category, Product, Order, OrderItem
prisma/seed.ts              демо-данные и первый админ
src/app/                    страницы (каталог, товар, корзина, checkout, кабинет, admin)
src/app/actions/            серверные действия (auth, checkout, admin)
src/lib/payments/           платёжные провайдеры
public/products/            демо-картинки товаров
uploads/                    фото, загруженные через админку (создаётся автоматически)
```

Цены хранятся в копейках. Название магазина и порог бесплатной доставки — в `src/lib/config.ts`.

## Продакшен

`npm run build && npm start`. Для продакшена рекомендуется PostgreSQL: поменяйте `provider` в `prisma/schema.prisma` на `postgresql` и `DATABASE_URL`. Загруженные фото лежат в папке `uploads/` — на хостинге нужен постоянный диск или перенос в S3-хранилище.
